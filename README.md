# Healthcare Analytics Project

## Project Overview
This project focuses on analyzing hospital
data to understand patient trends, hospital
operations, financial performance and
patient satisfaction.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Excel
- Power BI

## Project Modules
1. Hospital Overview
2. Patient & Demographic Analysis
3. Hospital Operations
4. Doctor & Appointment Analysis
5. Financial Analysis
6. Patient Satisfaction Analysis

## Key Objectives
- Analyze patient records
- Identify healthcare trends
- Analyze treatment costs
- Study patient satisfaction
- Create interactive dashboards

## Conclusion
This project helps understand hospital
performance through data analysis and
visualization.
